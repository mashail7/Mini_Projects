## Projects

### ♟️ [Aqua Chess](./Aqua-Chess/)

A desktop chess application featuring a custom-built Python chess engine and an immersive beach and ocean-inspired interface.

- **Type:** Desktop Application (Human vs. AI)
- **Language:** Python 3.10+
- **GUI:** PySide6 (Qt for Python)
- **Chess Logic:** python-chess
- **AI:** Custom-built chess engine with Negamax, Alpha-Beta Pruning, and Iterative Deepening
- **Status:** In Development

**Highlights:**
- Three AI difficulty levels: Beach Breeze, High Tide, and Tsunami.
- Custom-designed SVG chess pieces.
- Beach and ocean-inspired visual design.
- Real-time position evaluation and captured-piece tracking.
- Multithreaded AI calculations for responsive gameplay.
- Self-contained architecture with no external chess engine binaries or image and sound assets.
